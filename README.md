# ТЕХНОРЕМОНТ Vue Landing

Одностраничный сайт для ремонта холодильников и бытовой техники.

## Что внутри
- Vue 3 + Vite
- Three.js 3D-холодильник в hero-блоке
- Отдельные интерактивные 3D-модели холодильника, стиральной машины, морозильника и микроволновки в карточках услуг
- Параллакс от курсора и скролла
- Reveal-анимации при прокрутке
- 3D tilt карточек услуг
- Бегущая строка
- Адаптив под телефон/планшет/ПК
- Никаких форм заявок — только кнопки звонка

## Как запустить
```bash
npm install
npm run dev
```

## Как поменять номер
Откройте `src/App.vue` и замените:
```js
const phone = '+998 90 000 00 00'
const phoneHref = 'tel:+998900000000'
```

## Продакшн-сборка
```bash
npm run build
```
Готовая версия появится в папке `dist`.
